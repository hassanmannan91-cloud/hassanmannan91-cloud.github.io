# Star Force: Warp Crisis — public website

Static GitHub Pages site using actual game artwork and captured gameplay.

Publish this repository as `<username>.github.io` (root user site), then in Settings → Pages choose Deploy from a branch → main → /(root). This is important: Unity must find the seller file at https://<username>.github.io/app-ads.txt, not under a project subfolder.

Store links are intentionally disabled until the real URLs are added in config.json. The gameplay capture predates the latest game changes. No game source, signing keys, or builds belong in this public repository.
